### 2. Wire `hold` verdict handling

In both `manual-run.ts` and `event-orchestrator.ts`, after a stage completes with a skill signal:

**`hold/already_complete`:**
```typescript
// Resolve targetState key → stateId, then:
await issueService.stateOverride(issueId, targetStateId, issue.version, 'orchestrator');
```

**`hold/needs_human`:**
```typescript
// Set status to 'blocked' — no state change
await issueService.updateStatus(issueId, blockedStatusId, issue.version, 'orchestrator');
```

The `issueService.stateOverride()` method already exists in `src/core/services/issue.ts:460` — it bypasses transition validation and records `override: true` in the audit event.
