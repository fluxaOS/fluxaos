<objective>
## Goal
Implement persona lifecycle with CRUD, inheritance resolution (global → project → override), skill attach/detach, and tRPC routes. Personas are the identity layer that drives pipeline execution.

## Purpose
Every pipeline stage runs as a persona. The persona carries soul (personality), identity (behavior config), skills, routing preferences, and brand. Inheritance lets project personas extend global ones without duplicating config.

## Output
- `core/personas/` — types, service layer with inheritance resolution
- tRPC persona router with full CRUD + skill binding
- Tests covering CRUD, inheritance, and skill attach/detach
</objective>

  <files>src/core/personas/types.ts, src/core/personas/service.ts, src/core/personas/index.ts</files>
  <action>
    **types.ts:**
    - Define PersonaScope union: 'global' | 'project'
    - Define CreatePersonaInput: name (required), scope?, projectId?, soul?, identity? (Record), brandId?, routingProfileId?, parentPersonaId?
    - Define UpdatePersonaInput: all fields optional
    - Define PersonaFilter: projectId?, scope?
    - Define ResolvedPersona: persona fields with resolved (merged) identity and skills array

    **service.ts:**
    Follow the skill/issue service pattern:
    - createPersona(input) — insert into persona table, return created row
    - getPersona(id, resolve?: boolean) — if resolve=true, walk parentPersonaId chain and merge: parent soul is base, child soul overrides if set; parent identity keys merged with child overrides; include attached skills from personaSkill join
    - listPersonas(filters?) — filter by projectId/scope, order by name
    - updatePersona(id, updates) — update fields, return updated row
    - deletePersona(id) — delete persona + cascade personaSkill records
    - attachSkill(personaId, skillId, configOverrides?) — insert into personaSkill
    - detachSkill(personaId, skillId) — delete from personaSkill
    - listPersonaSkills(personaId) — query personaSkill join with skill details

    **Inheritance resolution logic:**
    - Walk parentPersonaId chain (max 3 levels to prevent infinite loops)
    - Merge identity: Object.assign({}, ...chain.map(p => p.identity)) with deepest parent first
    - Soul: use child soul if set, else parent soul
    - Skills: union of all skills from chain, with closest override's configOverrides winning
    - Brand/routing: use child if set, else parent

    **index.ts:**
    - Barrel export: all types, all service functions
  </action>
