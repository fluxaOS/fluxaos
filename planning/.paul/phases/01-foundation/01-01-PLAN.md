<objective>
## Goal
Create the `fluxaOS/fluxaos` GitHub repo and scaffold the complete project structure: Next.js 15 app with path aliases, Docker Compose (3 containers), and all directory skeletons — no business logic, just the bones everything else will build on.

## Purpose
Every subsequent plan depends on this structure existing. The directory layout, path aliases, and Docker Compose config lock in the foundational architecture decisions (no Turborepo, single Next.js app, 3-container deployment). Getting this right eliminates structural rework in later phases.

## Output
- `fluxaOS/fluxaos` repo initialized on GitHub with AGPLv3 license
- Next.js 15 app with `@/core`, `@/adapters`, `@/app`, `@/components`, `@/cli`, `@/config` path aliases
- Complete directory skeleton: `src/core/ports/`, `src/adapters/`, `src/app/`, `src/components/`, `src/cli/`, `src/config/`, `drizzle/`, `tests/`
- `docker-compose.yml` with fluxaos + postgres + redis containers
- `.env.example` with all required env vars
- ESLint + Biome config, TypeScript strict config, Vitest config
- Empty placeholder `index.ts` in each directory (so structure is committed)
- `package.json` with all dependencies for the full stack (installed but not yet wired)
</objective>

<task type="auto">
  <name>Task 2: Docker Compose with fluxaos + postgres + redis</name>
  <files>
    docker-compose.yml, docker-compose.override.yml (optional), Dockerfile
  </files>
  <action>
    1. Create `Dockerfile` (multi-stage, Next.js standard):
       ```dockerfile
       FROM node:22-alpine AS base
       WORKDIR /app
       COPY package*.json ./
       RUN npm ci

       FROM base AS dev
       COPY . .
       CMD ["npm", "run", "dev"]

       FROM base AS builder
       COPY . .
       RUN npm run build

       FROM node:22-alpine AS runner
       WORKDIR /app
       ENV NODE_ENV=production
       COPY --from=builder /app/.next/standalone ./
       COPY --from=builder /app/.next/static ./.next/static
       COPY --from=builder /app/public ./public
       CMD ["node", "server.js"]
       ```

    2. Create `docker-compose.yml` exactly matching spec:
       ```yaml
       services:
         fluxaos:
           build: .
           target: dev
           ports:
             - "3000:3000"
           environment:
             DATABASE_URL: postgres://postgres:postgres@postgres:5432/fluxaos
             REDIS_URL: redis://redis:6379
             NEXT_PUBLIC_SUPABASE_URL: ${NEXT_PUBLIC_SUPABASE_URL}
             NEXT_PUBLIC_SUPABASE_ANON_KEY: ${NEXT_PUBLIC_SUPABASE_ANON_KEY}
             SUPABASE_SERVICE_ROLE_KEY: ${SUPABASE_SERVICE_ROLE_KEY}
             FLUXAOS_GIT_PROVIDER: ${FLUXAOS_GIT_PROVIDER:-github}
             FLUXAOS_AUTH_PROVIDER: ${FLUXAOS_AUTH_PROVIDER:-supabase}
             FLUXAOS_REALTIME_PROVIDER: ${FLUXAOS_REALTIME_PROVIDER:-supabase}
             FLUXAOS_QUEUE_PROVIDER: ${FLUXAOS_QUEUE_PROVIDER:-bullmq}
             FLUXAOS_STAGE_EXECUTOR: ${FLUXAOS_STAGE_EXECUTOR:-node-exec}
           depends_on:
             postgres:
               condition: service_healthy
             redis:
               condition: service_healthy
           volumes:
             - .:/app
             - /app/node_modules
             - /app/.next

         postgres:
           image: postgres:16-alpine
           ports:
             - "5432:5432"
           environment:
             POSTGRES_DB: fluxaos
             POSTGRES_USER: postgres
             POSTGRES_PASSWORD: postgres
           volumes:
             - pgdata:/var/lib/postgresql/data
           healthcheck:
             test: ["CMD-SHELL", "pg_isready -U postgres"]
             interval: 5s
             timeout: 5s
             retries: 5

         redis:
           image: redis:7-alpine
           ports:
             - "6379:6379"
           healthcheck:
             test: ["CMD", "redis-cli", "ping"]
             interval: 5s
             timeout: 5s
             retries: 5

       volumes:
         pgdata:
       ```

    3. Add `output: 'standalone'` to `next.config.ts` (required for Docker runner stage):
       ```ts
       const nextConfig = {
         output: 'standalone',
       };
       export default nextConfig;
       ```

    4. Commit:
       ```
       git add docker-compose.yml Dockerfile next.config.ts
       git commit -m "chore: Docker Compose — fluxaos, postgres, redis"
       git push origin main
       ```
