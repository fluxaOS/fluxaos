<objective>
## Goal
Define the complete Drizzle ORM schema for all core entities from the spec data model, generate and run migrations against the Docker Postgres, and create a seed script with default org/project/pipeline config.

## Purpose
The schema is the foundation every subsequent plan builds on — issues, skills, personas, pipelines, routing, and observability all query these tables. Getting the schema right now prevents migration churn in later phases.

## Output
- `src/core/db/schema.ts` — all 18+ entity definitions with relations
- `src/core/db/index.ts` — Drizzle client export (connects to DATABASE_URL)
- `drizzle.config.ts` — Drizzle Kit config for migration generation
- `drizzle/` — generated SQL migration files
- `src/core/db/seed.ts` — seed script (default org, project, pipeline, 4 stages)
- All tables created in Docker postgres
</objective>

<task type="auto">
  <name>Task 1: Define Drizzle schema with all core entities</name>
  <files>src/core/db/schema.ts, src/core/db/index.ts, drizzle.config.ts</files>
  <action>
    1. Create `src/core/db/schema.ts` with ALL entities from the spec data model.

    Use `pgTable` from `drizzle-orm/pg-core`. For each table:
    - `id` — uuid, primary key, defaultRandom()
    - `created_at` — timestamp, defaultNow(), notNull
    - `updated_at` — timestamp, defaultNow(), notNull

    **Entity list (18+ tables):**

    **Organization & Project:**
    - `organization` — name (text, notNull), slug (text, unique, notNull), settings (jsonb)
    - `project` — org_id (uuid, FK→organization), name (text, notNull), slug (text, notNull), repo_url (text), default_pipeline_id (uuid, nullable FK→pipeline), brand_id (uuid, nullable FK→brand). Unique on (org_id, slug).

    **Pipeline:**
    - `pipeline` — project_id (uuid, FK→project), name (text, notNull), description (text), is_default (boolean, default false)
    - `pipeline_stage` — pipeline_id (uuid, FK→pipeline), name (text, notNull), sort_order (integer, notNull), persona_id (uuid, nullable FK→persona), harness (text), timeout_sec (integer, default 300), max_retries (integer, default 0), gate_mode (text, default 'auto' — enum: auto/rules/hold), gate_rules (jsonb)
    - `pipeline_run` — pipeline_id (uuid, FK→pipeline), issue_id (uuid, nullable FK→issue), status (text, notNull, default 'pending' — enum: pending/running/completed/failed/cancelled), started_at (timestamp), completed_at (timestamp), total_cost_usd (numeric(10,6), default 0)
    - `stage_run` — pipeline_run_id (uuid, FK→pipeline_run), pipeline_stage_id (uuid, FK→pipeline_stage), status (text, notNull, default 'queued' — enum: queued/running/completed/failed/cancelled/timed_out), provider (text), model (text), harness (text), cost_usd (numeric(10,6), default 0), tokens_in (integer, default 0), tokens_out (integer, default 0), started_at (timestamp), completed_at (timestamp)

    **Event Store (append-only):**
    - `event` — stage_run_id (uuid, FK→stage_run), type (text, notNull — enum: STAGE_STARTED/OUTPUT/TOOL_CALL/COST_UPDATE/GATE_EVALUATED/STAGE_COMPLETED/ERROR), payload (jsonb, notNull), timestamp (timestamp, defaultNow(), notNull). NO updated_at on this table — it's append-only.

    **Issues:**
    - `issue` — project_id (uuid, FK→project), title (text, notNull), description (text), state (text, notNull, default 'open'), priority (text, default 'medium'), type (text, default 'task'), created_by (text), source (text, default 'internal')
    - `issue_event` — issue_id (uuid, FK→issue), type (text, notNull), payload (jsonb), timestamp (timestamp, defaultNow(), notNull). NO updated_at — append-only.

    **Routing:**
    - `provider` — org_id (uuid, FK→organization), name (text, notNull), type (text, notNull), base_url (text), api_key_ref (text), is_healthy (boolean, default true)
    - `model` — provider_id (uuid, FK→provider), name (text, notNull), identifier (text, notNull), capabilities (jsonb), cost_per_1k_input (numeric(10,6)), cost_per_1k_output (numeric(10,6))
    - `routing_profile` — org_id (uuid, FK→organization), name (text, notNull), description (text), is_default (boolean, default false)
    - `routing_rule` — profile_id (uuid, FK→routing_profile), stage_name (text), allowed_models_pattern (text), preferred_harness (text), fallback_harness (text), sort_strategy (text, default 'quality'), max_cost_usd (numeric(10,6))

    **Personas & Skills:**
    - `persona` — scope (text, notNull, default 'project'), project_id (uuid, nullable FK→project), name (text, notNull), soul (text), identity (jsonb), brand_id (uuid, nullable FK→brand), routing_profile_id (uuid, nullable FK→routing_profile), parent_persona_id (uuid, nullable self-FK)
    - `skill` — scope (text, notNull, default 'project'), project_id (uuid, nullable FK→project), name (text, notNull), description (text), prompt_template (text), input_schema (jsonb), output_schema (jsonb), tags (jsonb), version (integer, default 1)
    - `persona_skill` — persona_id (uuid, FK→persona), skill_id (uuid, FK→skill), enabled (boolean, default true), config_overrides (jsonb). Primary key on (persona_id, skill_id).
    - `team` — project_id (uuid, FK→project), name (text, notNull), description (text)
    - `team_member` — team_id (uuid, FK→team), persona_id (uuid, FK→persona), role (text). Primary key on (team_id, persona_id).

    **Brand:**
    - `brand` — org_id (uuid, FK→organization), project_id (uuid, nullable FK→project), name (text, notNull), colors (jsonb), fonts (jsonb), tone_of_voice (text), style_guide (text), logo_url (text)

    **Memory:**
    - `memory` — scope (text, notNull, default 'project'), project_id (uuid, nullable FK→project), persona_id (uuid, nullable FK→persona), type (text, notNull), content (text, notNull), embedding (jsonb), relevance_score (numeric(5,4))

    **System:**
    - `config_entry` — scope (text, notNull, default 'global'), key (text, notNull), value (jsonb, notNull), previous_value (jsonb), changed_by (text)

    2. Define Drizzle relations using `relations()` from `drizzle-orm` for all foreign keys.

    3. Create `src/core/db/index.ts`:
       ```ts
       import { drizzle } from 'drizzle-orm/node-postgres';
       import pg from 'pg';
       import * as schema from './schema';

       const pool = new pg.Pool({
         connectionString: process.env.DATABASE_URL,
       });

       export const db = drizzle(pool, { schema });
       export type Database = typeof db;
       ```

    4. Create `drizzle.config.ts` in project root:
       ```ts
       import { defineConfig } from 'drizzle-kit';

       export default defineConfig({
         schema: './src/core/db/schema.ts',
         out: './drizzle',
         dialect: 'postgresql',
         dbCredentials: {
           url: process.env.DATABASE_URL!,
         },
       });
       ```

    5. Add scripts to `package.json`:
       ```json
       "db:generate": "drizzle-kit generate",
       "db:migrate": "drizzle-kit migrate",
       "db:seed": "tsx src/core/db/seed.ts",
       "db:studio": "drizzle-kit studio"
       ```

    6. Install tsx if not present: `npm install --save-dev tsx`

    7. Generate migration: `npx drizzle-kit generate`

    8. Run migration against Docker postgres:
       `DATABASE_URL=postgres://postgres:postgres@localhost:5432/fluxaos npx drizzle-kit migrate`
  </action>

  <done>AC-1 and AC-2 satisfied: all tables exist in postgres, tsc clean, migration generated</done>
